# 🛒 MerceariaMvc

Sistema web de gerenciamento de uma mercearia, desenvolvido utilizando ASP.NET Core MVC.

## 📋 Sobre o projeto

O MerceariaMvc é um sistema desenvolvido para auxiliar no gerenciamento de uma mercearia, permitindo o cadastro e gerenciamento de informações através de uma interface web.

O projeto utiliza o padrão arquitetural MVC (Model-View-Controller), proporcionando uma organização entre as regras de negócio, as páginas da aplicação e o controle das requisições.

## 🚀 Funcionalidades

- 🏠 Página inicial
- 📦 Cadastro de produtos
- 📋 Listagem de produtos
- ✏️ Edição de produtos
- 🔎 Visualização dos detalhes dos produtos
- 🗑️ Exclusão de produtos
- 👥 Cadastro e gerenciamento de clientes
- 💾 Integração com banco de dados
- 🎨 Interface estilizada com tema de mercearia

## 🛠️ Tecnologias utilizadas

- C#
- ASP.NET Core MVC
- Entity Framework Core
- SQL Server
- HTML
- CSS
- Bootstrap
- Visual Studio
- Git e GitHub
